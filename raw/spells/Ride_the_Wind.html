Ride the Wind

From bg3.wiki
Jump to navigation Jump to search
See also: Fly (disambiguation)
Not to be confused with Ride the Winds
Ride the Wind is a class action that allows a monk following the Way of the Four Elements to fly.

Description

Gain the ability to  Fly.

Properties

Cost
 Action +  4 Ki Points
Details
 Range: Self
 Concentration

Technical details

UID
Shout_Fly_Monk
Spell flags
HasSomaticComponent, IsConcentration

Grants:

  • Fly (class action)
  • Martial Arts: Bonus Unarmed Strike

Condition: Flight

 Flight

Duration: Until Long rest

  • Fly up to target position, up to 18 m (60 ft) each turn using your Movement Speed.

How to learn

Classes:
  • Class level 11: Way of the Four Elements
