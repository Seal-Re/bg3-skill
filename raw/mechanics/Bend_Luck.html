Bend Luck

From bg3.wiki
Jump to navigation Jump to search
"Bend Luck" redirects here. For the passive feature, see, see Bend Luck (passive feature).
Bend Luck is both a free action and reaction available to Wild Magic sorcerers that grants a bonus or penalty to a target's attack roll, ability check, or saving throw.

Description

Give a target a 1d4 bonus or penalty to  Ability Checks.

You can also apply this bonus or penalty to a target's  Attack Roll or  Saving Throw as a  Reaction.

Properties

Cost
 2 Sorcery Points
Details
 Range: 18 m (60 ft)

Technical details

UID
Target_BendLuck
Spell flags
HasHighGroundRangeExtension, Invisible, IsLinkedSpellContainer, Stealth

Variants

  •  Bend Luck: Ability Check Bonus
  •  Bend Luck: Ability Check Penalty

How to learn

Classes:
  • Class level 6: Wild Magic Sorcerer

Notes

  • If performed manually, this ability is a free action and applies  Bend Luck: Ability Check Bonus or  Bend Luck: Ability Check Penalty. It can only affect ability checks when manually activated like this.
  • If triggered as a reaction, this ability consumes a  Reaction resource and does not apply a condition. It only affects the triggering action that was reacted to.
  • As a reaction, this ability cannot affect the sorcerer's own rolls. When manually cast, it can target the sorcerer.
