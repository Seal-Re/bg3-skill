Fire Breath (Line)

From bg3.wiki
Jump to navigation Jump to search
This article is about the fire breath weapon used by Brass Dragonborn. For the version used by Red and Gold Dragonborn, see Fire Breath (Cone). For other uses, see Fire Breath (disambiguation).
Fire Breath is a brass dragonborn racial breath weapon. This action allows them to breathe a line of damaging flame in a target direction.

Description

Spew forth a column of fire.

Properties

Cost
 Action
Damage: 2~12
2d6⁠Fire
Details
 DEX Save (DC 8 + Constitution modifier + proficiency bonus) (On Save: Target still takes half damage.)
 Range: Self
 AoE: 5 m (17 ft) Line
 Recharge: Short rest

At higher levels

  • At character level 6, the damage increases to 3d6⁠⁠Fire.
  • At character level 11, the damage increases to 4d6⁠⁠Fire.

Technical details

UID
Zone_BreathWeapon_Fire_Line
Spell flags
CanAreaDamageEvade

How to learn

Races:
  • Character level 1: Brass Dragonborn

(Character level is the sum of all class levels for a multi-classed character.)

Notes

  • Breath weapons use spell save DC calculated using Constitution. This means that, despite the unusual casting ability, breath weapons still benefit from anything that improves spell save DC.
