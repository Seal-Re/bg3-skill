Burning (Condition)

From bg3.wiki
Jump to navigation Jump to search
Not to be confused with Infernal Burning (Condition) and Burning (Orthonic) (Condition)

Burning

  • Takes 1d4⁠⁠Fire damage per turn.
  • Can be removed with the  Help action, using a Healing Potion or gaining  Wet.
  • Immune from if  Wet.
  •  Dip action can be used on Burning characters or objects.

Properties

UID: BURNING

 Stack ID: BURNING

 Status groups: SG_Surface, SG_Light

 Loses duration: start of turn

 More properties:
  • InitiateCombat
  • Burning
  • DisableOverhead
  • IgnoreResting

Notes

  • Conditions that share the same StackID prevent the additional application of these conditions until the original condition has timed out. As a result, a character that is affected by  Burning will not also be affected by  Melting, meaning this character may walk around freely in lava while only receiving 1d4⁠⁠Fire damage instead of 10d6⁠⁠Fire damage.
  • Burning creatures take double damage from the  Fire Elemental's  Multiattack, and are made  Brittle by the  Water Elemental's  Winter's Breath.
  • Burning creatures take an additional 1d4⁠⁠Weapon damage when attacked by  Dragon's Grasp or  Firestoker.

Conditions with the same stack ID

Conditions with the stack ID BURNING, only one of these can be applied at the same time:
Condition Effects
Burning
  • Takes 1d4⁠⁠Fire damage per turn.
  • Can be removed with the  Help action, using a Healing Potion or gaining Wet.
  • Immune from if Wet.
  •  Dip action can be used on Burning characters or objects.
Burning (Orthonic)
  • Takes 1d4⁠⁠Fire damage per turn.
  • Cannot be removed with the  Help action, using a Healing Potion or becoming  Wet.
Burning Fiercely
  • Takes 1d10⁠⁠Fire damage per turn.
Holy Fire
  • Takes 1~4⁠⁠Radiant damage per turn.
Melting
  • Takes 10d6⁠⁠Fire damage per turn.
Roiling Hellfire
  • Flames from the heart of Avernus engulf this entity, inflicting 6d6⁠⁠Fire damage per turn.
Scorching Aura
  • Attacks dealt by this entity deal a bonus 1d6⁠⁠Fire unless it is made  Wet.
